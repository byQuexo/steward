# Data and asset licenses

Steward's demo data is **entirely synthetic**. No real people, companies, salaries, tickets or
documents are included, and no dataset under a non-commercial (CC-BY-NC) or unclear license is used.

| What | Where | Source | License |
|---|---|---|---|
| Names, cities, companies, job titles, ticket and chat text | `profiles/*/data/*.json` | Generated by [Faker](https://github.com/joke2k/faker) (`de_DE`, `en_US`) with a fixed seed | Faker: MIT. Output: synthetic, released with this repository under MIT OR Apache-2.0 |
| Policy documents (handbook, salary bands, VPN guide, …) | `profiles/*/seed/docs/*.md` | Written for this project | MIT OR Apache-2.0 |
| PDFs and page images | `profiles/*/data/docs`, `profiles/*/data/pages` | Rendered from the Markdown above with [reportlab](https://www.reportlab.com/) and [Pillow](https://python-pillow.org/) | reportlab: BSD; Pillow: MIT-CMU. Output: MIT OR Apache-2.0 |
| Font in page images | rendered into the PNGs | Bitstream Vera, shipped with reportlab | Bitstream Vera license (free use, embedding allowed) |
| Keycloak realm | `profiles/*/data/keycloak/realm.json` | Generated from the seed users | MIT OR Apache-2.0 |
| Demo passwords | `profiles/*/data/users.json` | Equal to the user id; **local demo realm only** | n/a |

The plan originally considered public datasets (Kaggle HR, CRM and helpdesk samples). They
were dropped: licenses varied per dataset and several were non-commercial, while synthetic
data covers every demo scenario and keeps the seed reproducible byte for byte
(`uv run steward-seed --profile profiles/<name> --check`, run in CI).
