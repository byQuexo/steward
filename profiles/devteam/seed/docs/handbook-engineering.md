# Engineering Handbook

This handbook applies to every engineer at Northwind Labs, remote or in the Lisbon and Toronto offices.
It replaces version 2026.1 and takes effect on 1 October 2026.

## Code review

Every change reaches main through a pull request. A pull request needs one approving review from a
code owner of the repository. Maintainers merge; authors never merge their own pull requests.
Reviews are answered within one working day.

## Branches

Feature branches are named after the issue, for example feat/142-retry-webhooks. Branches are deleted
after the merge. Force pushes to main are blocked for everyone.
<!-- page -->
## Working hours

Core hours are 11:00 to 15:00 in the engineer's local time zone. Meetings outside core hours are optional.

## Learning budget

Each engineer has a learning budget of 1,500 USD per calendar year for books, courses and conferences.
Requests go to the engineering lead in the people portal.
